## 3. ผลการวิเคราะห์ตอบคำถาม Q2: ระยะตลิ่งต่ำ $\rightarrow$ สัดส่วนรายงานน้ำท่วม

### 3.1 สัดส่วนรายงานน้ำท่วมตามระดับความเสี่ยงของระยะพ้นตลิ่ง (Risk Tier Correlation)

$$\text{Flood Report Ratio} = \frac{\text{จำนวนรายงานที่ระบุน้ำท่วม (Numerator)}}{\text{จำนวนรายงานทั้งหมดในแขวง-ชั่วโมงนั้น (Denominator)}}$$

| ระดับความเสี่ยง (Risk Tier) | นิยามระยะพ้นตลิ่ง (Freeboard) | ชั่วโมง-แขวง | รายงานทั้งหมด (ตัวหาร) | รายงานน้ำท่วม (ตัวตั้ง) | รายงานไม่แน่ชัด | สัดส่วนรายงานน้ำท่วม (%) |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 🔴 **CRITICAL_OVERFLOW** | $\le 0.0\text{ m}$ (น้ำล้นตลิ่ง) | 912 | 2,710 | 2,350 | 14 | **86.72%** |
| 🟠 **HIGH_ALERT** | $0.0 < \text{Freeboard} \le 0.5\text{ m}$ (เฝ้าระวังสูงสุด) | 940 | 2,845 | 2,400 | 17 | **84.36%** |
| 🟡 **WATCH** | $0.5 < \text{Freeboard} \le 1.0\text{ m}$ (เฝ้าระวัง) | 952 | 1,956 | 1,096 | 10 | **56.03%** |
| 🟢 **NORMAL** | $> 1.0\text{ m}$ (ระดับน้ำปกติ) | 661 | 911 | 232 | 3 | **25.47%** |
| ⚪ **SUSPECT_DATUM** | สถานี ID 10 (`usable_for_freeboard=false`) | 319 | 543 | 367 | 6 | 67.59% |
| ⚫ **NO_TELEMETRY** | ช่องเวลาที่ไม่มีสัญญาณระดับน้ำ | 188 | 649 | 576 | 5 | 88.75% |

> **สรุปผลวิเคราะห์เชิงสถิติ (Key Finding):**  
> เมื่อคัดแยกสถานี ID 10 ที่มีปัญหา Vertical Datum Mismatch ออกไป พบความสัมพันธ์เชิงบวกแบบเป็นขั้นบันได (Monotonic Relationship) อย่างชัดเจน: ในสภาวะปกติ (`NORMAL`) สัดส่วนรายงานน้ำท่วมอยู่ที่เพียง **25.47%** แต่เมื่อระดับน้ำเข้าใกล้ตลิ่ง (`HIGH_ALERT`) และล้นตลิ่ง (`CRITICAL_OVERFLOW`) สัดส่วนรายงานน้ำท่วมพุ่งสูงถึง **84.36% – 86.72%** (เพิ่มขึ้นกว่า **3.4 เท่า**)

### 3.3 ข้อจำกัดของข้อมูลและการตีความ (Data & Model Limitations)
1. **เวลาในการแจ้งเตือน (Reporting Lag):** เวลาใน Traffy Fondue คือเวลาที่ประชาชนกดส่งเรื่องแจ้ง ไม่ใช่เวลาที่น้ำเริ่มท่วมจริง
2. **การแจ้งซ้ำในเหตุการณ์เดียวกัน (Incident Clustering):** ในจุดที่มีน้ำท่วมขังบนถนนสายหลัก มักมีประชาชนแจ้งปัญหาเดียวกันหลายใบ
3. **การเข้าถึงและความครอบคลุมของสถานีวัดน้ำ (Hydrological Connectivity):** การจับคู่ด้วยระยะทางสถานีที่ใกล้ที่สุดเป็นการประมาณเชิงภูมิศาสตร์ อาจมีบางแขวงที่เกิดน้ำท่วมขังรอการระบายบนผิวจราจรแม้คลองหลักยังไม่ล้นตลิ่ง
4. **ความคลาดเคลื่อนของ API ต้นทาง:** ข้อมูล API สาธารณะของ Traffy แจ้งยอด `total` สูงกว่าจำนวนแถวที่ดึงได้จริงประมาณ 40–69 รายการต่อวัน
